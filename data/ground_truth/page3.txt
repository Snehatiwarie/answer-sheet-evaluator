• 01. Operating System Overview •
* Operating system provide interaction between user and computer.
Booting sequence - starting a computer or computer embedded device.
STEPS : 1) Switching on power supply
2) Loading of OS into computer main memory (BIOS will load OS)
3) Keeping all application in a state of readiness in case needed by user.
BIOS = - Basic Input Output System (ROM (present in ROM))
- always on
- firmware (hardware + software)
• Cold booting - 1) Switching on power
2) Loading BIOS
• Warm Booting - when system is already running and need to restart
warm booting is faster (bcz OS is already loaded)
* Objectives of operating system :
* To make computer system more convenient.
* To hide hardware details from users.
* Provide interface bet^n user and computer.
