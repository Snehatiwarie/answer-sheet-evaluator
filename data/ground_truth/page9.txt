A class is a blueprint or template for creating objects.   Object:
An object is a real instance of class.   Class -> Car
Objects -> BMW, Audi, Tesla   Class does not occupy memory
Object occupies memory   class Car {

}   Class defines properties   Objects use those properties   Class defines, Object represents
